# Rafael Marques Terminal Portfolio

A terminal-style portfolio for Rafael Marques, built with React, TypeScript and
Styled Components.

## Features

- Responsive terminal interface
- Autocomplete with `Tab` or `Ctrl+I`
- Command history and keyboard navigation
- Seven color themes, including Catppuccin Mocha
- PWA and offline support
- Vitest test suite

Type `help` in the terminal to see the available commands.

## Development

```bash
pnpm install
pnpm dev
```

Run the checks:

```bash
pnpm test:once
pnpm lint
pnpm build
```
